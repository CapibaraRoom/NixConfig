## Установка

Для настройки сети во время установки можно использовать утилиту `nmtui`.

Пример разметки диска и монтирование разделов:
- **nvme0n1p1** (*fat32*) 128Мб - загрузочный раздел **/boot**
- **nvme0n1p2** (*ext4*) 1Гб - раздел для хранения конфигураций **/etc/nixos**
- **nvme0n1p3** (*ext4*) 50Гб - системный раздел **/**

```
sudo mount /dev/nvme0n1p3 /mnt
sudo mkdir -p /mnt/boot
sudo mount /dev/nvme0n1p1 /mnt/boot
sudo mkdir -p /mnt/etc/nixos
sudo mount /dev/nvme0n1p2 /mnt/etc/nixos
```

После установки система будет весить до 30 Гб. Необходим запас на разные нужды и компиляции программ (50Гб вполне достаточно).

Генерация конфигурации оборудования:
```
sudo nixos-generate-config --root /mnt
```

Применение конфига для системы **"defaultsystem"** (запуск установки):
```
sudo nixos-install --flake /etc/nixos#defaultsystem
```


## Известные проблемы

- Не обновляется погода в Noctalia при использовании несколькими пользователями *(я вертел все авокада того разраба, который не выставил права на запись tmp-файлов в noctalia)*
- Неподходящие по теме мультимедиа-компоненты: ImageViewer, VideoPlayer, FileManager *(проще и быстрее сделать кастомные, как только закончатся работы над движком)*
- Отсутствие шрифтов в OnlyOffice *(разрабы похерили использование линков; проще скопировать вручную: `cp -rL /usr/share/X11/fonts ~/.local/share/fonts` )*
- Компоненты на Rust *(позже всю ересь переведу на праведный C++ или Go, но это займёт время)*


## Некоторые команды nix
| Команда | Назначение |
|---|---|
| `nix-shell` | Запускает интерактивный шелл в окружении. |
| `nix-shell "$HOME/.nixdev.nix" --run "exec zsh"` | Запускает шелл с указанием его конфигурации. |
| `nixos-rebuild switch --flake /etc/nixos#${HOST}` | Активирует конфиг и добавляет его в меню GRUB. |
| `nixos-rebuild test --flake /etc/nixos#${HOST}` | Активирует конфиг до перезагрузки. |
| `nixos-rebuild dry-build --flake /etc/nixos#${HOST}` | Собирает конфиг, не активируя его (проверка). |
| `nixos-rebuild build-vm --flake /etc/nixos#${HOST}` | Собирает QEMU-образ для запуска в VM. |
| `nix-collect-garbage -d` | Удаляет старые поколения и мусор из store. |
| `nix-store --optimize` | Форматирует store через hardlinks. |
