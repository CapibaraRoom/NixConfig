Mango:

WIN + backspace              - выход из mangowm
WIN + m                      - перезагрузка конфигурации mangowm

WIN + n                      - смена тайлинга
WIN/ALT + Tab                - обзор окон

WIN + WASD/стрелки           - перемещение по окнам в одном теге
ALT + WASD/стрелки           - перемещение по окнам между тегами
WIN+Shift + WASD/стрелки     - перемещение окна в одном теге
WIN+Ctrl + WASD/стрелки      - вписывание окна в одном теге

Ctrl+ALT + WASD/стрелки      - перемещение окна по тегам
ALT + 1-9                    - перемещение окна в тег
Ctrl + 1-9                   - переход к тегу

WIN+Shift + r                - изменение размера окна
WIN + r                      - развернуть окно
WIN + f                      - полноэкранный режим окна
WIN + z                      - свернуть окно (WIN+Shift + z - для восстановления)
WIN + x                      - плавающий режим окна
WIN/ALT + q                  - закрыть окно

Ctrl+Shift + AD/стрелки      - перемещене фокуса между мониторами
WIN+Ctrl+Shift + AD/стрелки  - перемещение окна между мониторами

WIN + MBL                    - перемещение окна
WIN + MBR                    - изменение размеров окна
WIN + Scroll                 - перемещение по тегам

WIN/ALT + Enter/t;           - открыть терминал (стандарт: Ctrl+ALT + t)
WIN + Space                  - запуск лаунчера
WIN + E; PrntScr             - создание скриншота
WIN + l                      - блокировка сессии
WIN + v                      - буфер обмена


Kitty:

Ctrl+Shift + t               - открыть новую вкладку
Ctrl+Shift + [               - горизонтальный сплит
Ctrl+Shift + ]               - вертикальный сплит
Ctrl+Shift + p               - развернуть сплит
Ctrl+Shift + стрелки         - перемещение по сплитам
Ctrl+Shift + backspace       - закрыть сплит
